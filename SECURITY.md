# Security Policy

## Supported versions

Frank is currently maintained on the latest revision of the `main` branch. Security fixes are not backported to older revisions.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or social-media post.

Preferred reporting method:

1. Open this repository's **Security** tab.
2. Select **Report a vulnerability** to submit a private report.

If private vulnerability reporting is unavailable, contact [@nmorton on X](https://x.com/nmorton) to request a private reporting channel. Do not include sensitive vulnerability details in a public message.

Please include, when possible:

- a description of the issue and its potential impact;
- affected endpoints, components, or versions;
- reproduction steps or a minimal proof of concept; and
- any suggested mitigation.

You should receive an acknowledgment within seven days. Please allow reasonable time for investigation and remediation before public disclosure.
